MOD 03Write-Ahead Log Engine

Enforces the WAL protocol: no data page is written to the main file until the change is sequentially appended to the log. Crash recovery replays the WAL on boot.

MOD 04Disk-Backed B+Tree Engine

Parent and leaf nodes map directly to 4KB Page Numbers. A key seek unpacks the binary buffer and binary-searches down the tree — under 4 disk reads for a 1M-row table.
